# Drawer inventory

A searchable inventory of the electronic component drawers, built from a video pan across the
cabinets. The browsable parts list is published at
**https://jsmnbom.github.io/drawers/** (deployed from `site/` by GitHub Actions on every push).

## Layout

| Path | What |
|---|---|
| `inventory.json` / `inventory.md` | OCR-derived inventory, generated by `work/categorize.py`. Do not hand-edit. |
| `verify.json` | Human verification edits, written by the verification tool. |
| `inventory_verified.json` / `.md` | `inventory.json` merged with `verify.json` (`work/export_verified.py`). |
| `tool.py` + `tool.html` | Local verification tool: `.venv/bin/python tool.py`, then open http://localhost:8765. Needs the full-size keyframes in `frames/` (not committed). |
| `work/` | Pipeline scripts (keyframe selection, OCR, dedup, categorisation) and OCR outputs. |
| `site/` | Static browse site. Rebuild with `cd work && ../.venv/bin/python build_site.py`. |
| `HANDOFF*.md` | Working notes on how the pipeline was built. |

The source video and the 529 full-size keyframes are not in the repo; `site/frames/` holds
downscaled copies of the frames referenced by the inventory.
